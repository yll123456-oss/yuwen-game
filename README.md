# 语文小乐园 · 小学语文 1-3 年级闯关小游戏

纯前端小游戏，覆盖新版人教版教材一年级至三年级的内容，无需安装，双击即可玩。朗读优先使用设备自带的中文语音（离线可用），设备没有中文语音或朗读失败时，会自动切换到在线发音（百度/谷歌，需要联网）。

## 运行方式

方式一（最简单）：直接双击 `index.html`，用浏览器打开即可。

方式二（本地服务器）：

```bash
cd 小语1-3测试
python3 -m http.server 8000
```

然后访问 http://localhost:8000

## 玩法

每册分两大章节，按顺序解锁：

- 第一章 · 基础字词：识字（认字、拼音、组词）→ 写字（笔画数、第一笔、结构、临写）→ 默写（听写汉字、听写词语、看拼音写汉字、补全词语）
- 第二章 · 日积月累 · 古诗词：每首古诗词先看作者简介、创作背景、逐句讲解、译文、注释和赏析，再闯关答题（选择题 + 默写）

答对一题 +1 金币，通关按星级额外奖励金币，攒够金币可以解锁成就称号。进度和金币自动保存在浏览器本地。

## 游戏形象

主角是原创角色「汤圆小侠 · 圆圆」：白白胖胖的糯米汤圆，头顶一朵桂花，暖粉色腮红。形象用内嵌 SVG 手绘 + CSS 动画实现，不引用任何图片文件，也不使用任何第三方 IP 的造型、配色或名称，因此不涉及形象授权。

- 平常状态：呼吸弹跳 + 眨眼 + 头顶热气
- 答对：跳起来冒小星星，表情变成笑眼
- 答错：左右摇晃，表情变成失落
- 册页面有一条闯关进度轨道，圆圆会随着通关进度往前移动

## 内容说明

数据依据新版人教版（2024-2026 学年）教材整理，来源与校对过程见《教材抓取参考.md》和《教材资料清单.md》。整理时遵循“只收录有网页来源的字表，拿不准的标‘待校对’”的原则，最终以纸质课本为准。

- 生字课：一年级上 280 识字 / 100 写字，一年级下 410 识字 / 200 写字，二、三年级按新版教材逐课整理
- 古诗：共 42 首，含正文、作者、出处、逐句讲解、译文、注释、赏析与配套题目
- 笔顺数据（`WRITE_DATA`）覆盖常用会写字；未覆盖的字在界面中会提示“待录入”

## 扩展或修改

- 加课、加诗：编辑 `data.js` 中对应册的数组即可（格式见现有条目）
- 改题目：`index.html` 顶部的 `buildReadQuestions` / `buildWriteQuestions` / `buildDictateQuestions` 控制自动出题
- 重置进度：清空浏览器本地存储中的 `yuwen-1-3-test-progress-v1` 和 `yuwen-1-3-test-coins-v1`，或在控制台执行 `localStorage.clear()` 后刷新
